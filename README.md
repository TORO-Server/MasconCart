トロッコに乗車して、Dキーを押すとマスコンモードのON/OFFができます。
Wキーでノッチアップ(加速)、Sキーでノッチダウン(ブレーキ)、AキーでNニュートラルを押して操作します。
最大P7、B1〜B7、EBを投入できます。
マスコンOFF中はWキーで通常発進できます。
停車中はスペースキーで進行方向を切り替えられます（押しっぱなしでは連続切替しません）。
マスコンON中はTrainCartsの看板制御が無視されるようになります。アナウンスなどは継続されます。

Minecraft 1.20以降向け

ビルド時のAPI: TrainCarts 2.0.2 / BKCommonLib 2.0.4 / ProtocolLib 5.4.0。
サーバーには使用するMinecraftに対応したTrainCarts・BKCommonLib・ProtocolLibを導入してください。
Java 17以降で `./gradlew build`（Windowsは `gradlew.bat build`）を実行すると、
`build/libs/MasconCart-1.3.3.jar` が生成されます。

1.3.2ではMinecraft 1.21.2以降の入力形式に対応し、速度・方向転換をTrainCarts APIで制御します。
マスコンをONにすると既存の駅待機・発車アクションを解除します。
OFF・降車・ログアウト時には元の速度制限と看板スキップ設定を復元します。

実機確認: DでON → Wを押してP1に変更 → 東西・南北それぞれのレールで停止状態から発進。
AでN、Sでブレーキ、停止後の素手右クリックで方向転換、DでOFFも確認してください。
実サーバー上での動作確認は別途必要です。

1.3.3ではマスコンON中にパワードレールの通電による加速・非通電によるブレーキを無効化します。
OFF・降車・ログアウト・プラグイン停止時に通常のレール制御へ戻ります。
実機では通電・非通電のパワードレール上でP1発進、N惰行、EB停止を確認してください。

現在の版はバージョン表記を1.3.3とし、追加済みの操作・連携機能を含みます。
加速量は2tickごとにP1だけ速度を0.005増やし、P2〜P7は従来どおり0.02増やします。
P1〜P7の目標速度（約17・34・51・69・86・103・120 km/h表示）に達すると惰行し、目標を下回ると再加速します。
起動加速度や加速度の立ち上がりによる制限はありません。
Nは2tickごとに速度を0.995倍、B1〜B7は0.007×段数を減速し、EBは即時停止します。
マスコンOFF中（`/mascon off`による無効化も含む）はTrainCartsの手動移動を有効にします。
ON中は手動移動を無効にして、Wキーをノッチ操作に使います。
停車時のスペースキーで方向転換できます。走行中と、他のプレイヤーがマスコン操作中の列車では切り替えません。
従来の素手右クリックによる方向転換も利用できます。

[Click-to-Minecart](https://github.com/punipuni-3730/Click-to-Minecart)が生成する`cminecart`タグ付きトロッコは、
乗車中にTrainCartsの管理へ変換してマスコンで操作できるようにします。
TrainCartsが無効なワールドなど、変換できない環境では利用できません。
タグやトロッコ本体は維持し、Click-to-Minecart側の降車時削除処理に引き継ぎます。

実機確認: Click-to-Minecartで生成して乗車 → OFFのままW発進 → 停車後スペースを一度押す →
DでONにしてWでノッチ操作 → EBで停止後スペースで反転 → DでOFFにしてW発進 → 降車時の削除。
走行中のスペースやスペース長押しで、方向が連続して変わらないことも確認してください。
